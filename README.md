# Tamilselvan N: Portfolio

Pure HTML, CSS and JavaScript. Open `index.html` locally to preview; no server needed.

## Publish on GitHub Pages
1. Create a free account at github.com (username `tamilselvann98`).
2. Click **New repository**, name it exactly `tamilselvann98.github.io`, set it Public, create it.
3. Click **Add file > Upload files**, drag in everything inside this folder (index.html, css, js, assets, README.md), then **Commit changes**.
4. Go to **Settings > Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, and Save.
5. After 1-2 minutes the site is live at https://tamilselvann98.github.io

## Update later
Edit a file on GitHub (pencil icon) or upload a replacement, then commit. The site refreshes in a minute or two.

## Resume
Replace `assets/resume/Tamilselvan_N_Resume.pdf` with your final one-page resume, keeping the same file name.

## Custom domain (optional)
Buy a domain, then in Settings > Pages enter it under Custom domain and add the DNS records GitHub shows you.
